## 🌟 O Diferencial para Recrutadores

Certificados estáticos em PDF não comprovam habilidade prática. Este projeto foi desenvolvido para resolver esse problema, transformando a validação de conhecimento em uma **experiência web interativa e auditável**:

* ⚡ **Validação em Tempo Real:** QR Code dinâmico integrado diretamente ao ecossistema do desenvolvedor no GitHub.
* 📊 **Métricas Visuais de Proficiência:** Gráficos interativos que mostram o nível real de domínio sobre cada stack.
* 🛠️ **Arquitetura Client-side Leve:** Customização total e persistência de dados local sem dependência de backend pesado.

## ✨ Funcionalidades Principais

- [x] ✏️ **Edição em Tempo Real:** Modal interativo para personalizar nome, título do curso, carga horária, data e descrição.
- [x] 📁 **Gerenciador de Repositórios:** Adição e remoção dinâmica de projetos com links diretos para o GitHub.
- [x] 💾 **Persistência Local (LocalStorage):** Todas as alterações do certificado são mantidas mesmo após recarregar a página.
- [x] 📲 **QR Code Dinâmico:** Geração automática via API vinculada ao perfil de quem está visualizando.
- [x] 🖨️ **Exportação Profissional (PDF):** CSS otimizado via `@media print` para geração de PDF limpo, sem elementos de interface.
- [x] 🛡️ **Selo Digital & Blockchain Mock:** Interface com elementos modernos de autenticidade visual.

## 💻 Como Executar o Projeto

Não é necessário instalar gerenciadores de pacotes pesados. O projeto roda nativamente em qualquer navegador moderno.

### Pré-requisitos
* Git instalado na sua máquina
* Qualquer navegador web moderno (Chrome, Edge, Firefox, Brave)

### Passo a passo

```bash
# 1. Clone o repositório
git clone [https://github.com/SEU-USUARIO/portfolio-certificado.git](https://github.com/SEU-USUARIO/portfolio-certificado.git)

# 2. Entre na pasta do projeto
cd portfolio-certificado

# 3. Abra o arquivo index.html no navegador
# No Linux/Mac:
open index.html
# Ou simplesmente dê dois cliques no arquivo index.html na sua pasta local.
