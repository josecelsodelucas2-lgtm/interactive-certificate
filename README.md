🎓 Certificado Interativo & Portfólio Web

Uma releitura moderna e funcional de certificados de desenvolvimento web: mais do que horas de curso, uma forma interativa de demonstrar projetos reais, competências práticas e links diretos para o GitHub.

🚀 Demonstração Online

🔗 Acesse a aplicação no ar: Clique aqui para visualizar
🔗 **Link do Projeto:** [Ver Certificado Online](https://josecelsodelucas2-lgtm.github.io/portfolio-certificado/)

📸 Visão Geral

O projeto recria a interface de um certificado digital futurista voltado para a área de tecnologia, composto por:

Painel Lateral com QR Code: Gera em tempo real um QR Code vinculado ao perfil do GitHub configurado.

Selo Digital & Blockchain: Elementos visuais de autenticidade e verificação.

Grade de Tecnologias: Demonstração visual de stacks dominadas (HTML5, CSS3, JavaScript, TypeScript, React, Node.js, Express, Git).

Projetos Autênticos: Lista de projetos dinâmicos com links diretos para seus respectivos repositórios.

Gráfico de Domínio: Indicador circular em SVG com níveis de proficiência (Intermediário, Avançado e Especialista).

🛠️ Tecnologias Utilizadas

✨ Funcionalidades

[x] Edição em Tempo Real: Modal interativo que permite alterar o nome do titular, título do curso, carga horária, data e descrição.

[x] Gerenciamento de Repositórios: Adicione ou remova projetos com nomes, descrições e links customizados.

[x] Persistência de Dados: Alterações são gravadas diretamente no localStorage do navegador.

[x] QR Code Dinâmico: Gerado automaticamente via API com base no link do seu GitHub.

[x] Modo Impressão / Salvar PDF: Estilos @media print otimizados para exportar o certificado de forma limpa.

💻 Como Rodar Localmente

Clone o repositório ou baixe os arquivos:

git clone https://github.com/SEU-USUARIO/portfolio-certificado.git


Abra a pasta do projeto:

cd portfolio-certificado


Basta dar dois cliques no arquivo index.html ou abri-lo pelo seu navegador favorito.
